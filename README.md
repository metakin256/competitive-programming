# 競技プログラミング 解法コード集 (Competitive Programming)

AtCoder などの競技プログラミングの過去問解法・提出コード置き場です。

## クラウド（GitHub）での検索のコツ
ファイル冒頭に以下のようなコメントを書いておくと、GitHub の検索バー（または `/` キー）で日本語キーワードから即座にコードを見つけられます。

```cpp
// 問題: AtCoder ABC 350 C - Sort
// URL: https://atcoder.jp/contests/abc350/tasks/abc350_c
// アルゴリズム: 幅優先探索 (BFS), 転倒数
```

## フォルダ構成の例
- `solution.cpp` : 最新の解法コード
- `solution_fixed.cpp` : 修正・改善版
- `snippets/` : よく使うテンプレート（Union-Find, Dijkstra, MOD逆元など）
